# Status Animarum Münster 1749/50

**NL** · Doorzoekbare index van de getypte afschriften (Abschriften) van de Status Animarum van het Prinsbisdom Münster, 1749–1751: 106 parochies, 1.902 scans. De site staat op **https://gerritjan-bit.github.io/status-animarum-1749/** *(in opbouw)*.

**DE** · Durchsuchbarer Index der maschinengeschriebenen Abschriften des Status Animarum des Fürstbistums Münster, 1749–1751: 106 Kirchspiele, 1.902 Scans. Die Website: **https://gerritjan-bit.github.io/status-animarum-1749/** *(im Aufbau)*.

**EN** · Searchable index of the typed transcripts (Abschriften) of the Status Animarum of the Prince-Bishopric of Münster, 1749–1751: 106 parishes, 1,902 scans. The site: **https://gerritjan-bit.github.io/status-animarum-1749/** *(under construction)*.

## Bron · Quelle · Source

De scans zijn van het Bistumsarchiv Münster en staan op [Matricula Online](https://data.matricula-online.eu/) onder CC BY-NC-ND 2.0. Deze repository bevat **geen scans**, alleen de met OCR gelezen tekst, de indeling in huishoudens en de correcties, met bij elke vermelding een link naar de scan.

Die Scans stammen aus dem Bistumsarchiv Münster und stehen bei Matricula Online unter CC BY-NC-ND 2.0. Dieses Repository enthält **keine Scans**, nur den per OCR erkannten Text, die Gliederung in Haushalte und die Korrekturen, jeweils mit Link zum Scan.

The scans belong to the Bistumsarchiv Münster and are published on Matricula Online under CC BY-NC-ND 2.0. This repository contains **no scans**, only the OCR text, the division into households and the corrections, each linked to its scan.
